# handwrite-ppt-editor

把文章、讲稿、提纲、结构或逻辑制作成可编辑的 16:9 手写风 HTML 幻灯片。

核心流程：

1. 先确认页数、故事线和重点；
2. 生成第一版 HTML；
3. 保留原有手绘 SVG、曲线、流程图和示意图；
4. 在 HTML 中编辑文本、位置、大小、字号、行距和颜色；
5. 保存独立 HTML；
6. 从确认后的当前 HTML 导出 PDF。

适合：

- 文档转手写 PPT；
- 手写流程图、表格和知识图解；
- 需要先编辑确认、再导出 PDF 的演示稿；
- 不希望 PPTX 转换丢失原始手写图形的场景。

使用：

```text
使用 $handwrite-ppt-editor。
先根据这篇文章和我的目标页数生成可编辑 HTML。
保留手绘流程图和示意图，先不要导出 PDF。
```

确认内容后：

```text
我已经修改并确认 HTML，请从当前版本导出 PDF。
```
